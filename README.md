# PsswdChecker

![Python](https://img.shields.io/badge/Python-3-3776AB?logo=python&logoColor=white)
![GUI](https://img.shields.io/badge/GUI-customtkinter-2b2b2b)

Анализатор надёжности паролей с графическим интерфейсом и консольным режимом. Оценивает пароль по набору критериев, сверяет его со списком из 10 000 самых распространённых паролей и показывает итоговый уровень.

## Что проверяется

| Критерий | Условие |
|---|---|
| Длина | не менее 12 символов |
| Цифры | есть хотя бы одна |
| Заглавные буквы | есть хотя бы одна |
| Строчные буквы | есть хотя бы одна |
| Спецсимволы | есть хотя бы один |
| Повторы | не более двух одинаковых символов подряд |

Пароль из списка распространённых получает уровень «Слишком простой» независимо от остальных критериев; короче 8 символов — «Очень короткий». Остальные уровни — «Слабый», «Средний», «Хороший», «Отличный» — по числу выполненных критериев.

## Запуск

```bash
git clone https://github.com/Wert01/PsswdChecker.git
cd PsswdChecker
pip install customtkinter

python main.py    # графический интерфейс
python psswd.py   # консольный режим
```

## Структура

```
├── main.py          # точка входа GUI
├── ui.py            # интерфейс на customtkinter (анимированная шкала, переключатель показа пароля)
├── psswd.py         # логика оценки пароля
└── most_common.txt  # 10 000 распространённых паролей
```

Логика (`psswd.py`) не зависит от интерфейса и может использоваться как модуль: `analyze_password(password)` возвращает `Evaluation` с критериями, оценкой и сообщением.

## Заметки

Проект начался как разминка по Python и перерос в небольшую утилиту. Пароль обрабатывается локально, никуда не отправляется и не сохраняется.
